Task 2: Command Line Fundamentals

1. Commands Practised

During this task, I practised the following Linux commands:

- "mkdir" - Creates directories.
- "touch" - Creates empty files.
- "echo" - Writes text into files.
- "cat" - Displays file contents.
- "head" - Displays the first lines of a file.
- "tail" - Displays the last lines of a file.
- "wc -l" - Counts the number of lines.
- "cp" - Copies files.
- "mv" - Moves or renames files.
- "ls -l" - Displays files with detailed information.
- "tree" - Displays directories and files in a tree structure.

2. Explanation of Important Commands

- "mkdir -p": Creates directories, including parent directories.
- "touch": Creates an empty file.
- "cp": Copies a file from one location to another.
- "mv": Moves or renames a file.

3. Difference Between > and >>

- ">" writes content into a file and replaces existing content.
- ">>" appends new content to a file without deleting existing content.

4. File Permissions

I used "ls -l" to inspect file permissions.

I observed that:

- "r" means read permission.
- "w" means write permission.
- "x" means execute permission.

File permissions determine who can read, modify, or execute a file.
