# Task 1: Basic Command Line Operations

## Commands Practised

1. `pwd` - Displays the current working directory.
2. `ls` - Lists files and directories.
3. `ls -la` - Lists all files, including hidden files, with details.
4. `cd` - Changes the current directory.
5. `cd ..` - Moves to the parent directory.
6. `mkdir` - Creates directories.
7. `mkdir -p` - Creates nested directories.
8. `touch` - Creates empty files.
9. `find` - Searches for files and directories.
10. `whoami` - Displays the current username.
11. `date` - Displays the current date and time.
12. `hostname` - Displays the computer's hostname.

## What I Learned

I learned how to navigate the Linux file system, create and manage files and directories, identify my current location, and search for files using command-line tools.
